1. Right-click PowerShell → Run as administrator, then:
cd D:\Project\Studio_Managment\backend

Creates D:\Project\Studio_Managment\deploy\ca.cer + agstudio.pfx.
2. Edit backend\.env — add/change:
PORT=8443
HTTPS_PFX=..\deploy\agstudio.pfx
HTTPS_PFX_PASS=studio123
SESSION_SECURE=true
(Use 8443 for the local test — 443 needs admin every time you restart. On the studio server the service runs as SYSTEM, so 443 is fine there.)
3. Stop the server (Ctrl+C) and run npm start again → you should see AG Studio serving HTTPS on https://0.0.0.0:8443.
4. Install deploy\ca.cer: right-click → Install Certificate → Local Machine → Trusted Root Certification Authorities.
5. Edit C:\Windows\System32\drivers\etc\hosts (notepad as admin), add:
127.0.0.1    agstudio.com
6. Open https://agstudio.com:8443 — no certificate warning, login works.
Two reminders:
When you're done testing, remove that hosts line or the service cert will interfere with the real deployment later.
npm start doesn't auto-reload — if you change code while testing, rebuild (npm run build) and restart the server.
